# Contribuindo

| Tema | Regra |
|---|---|
| Código externo | O projeto é desenvolvido por agentes e **ainda não aceita** contribuições de código externas |
| Issues | Bem-vindas (bugs, dúvidas, sugestões). Vulnerabilidades: veja [`SECURITY.md`](SECURITY.md) |
| CLA | Será exigido quando as contribuições abrirem (ADR 0009) |
| Commits e títulos de PR | [Conventional Commits](https://www.conventionalcommits.org/) |

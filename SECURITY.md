# Política de segurança

## Como reportar

Reporte vulnerabilidades **somente** pelo relato privado de vulnerabilidades do GitHub:
<https://github.com/aleogr/iam/security/advisories/new>

**Nunca** abra issue pública nem comente em PR com detalhes de vulnerabilidade.

| Item | Compromisso |
|---|---|
| Confirmação de recebimento | Em até 3 dias úteis |
| Divulgação | Coordenada: o relato fica privado até a correção estar disponível |
| Correções | Lançadas como releases só de segurança, separadas das releases de funcionalidade (ADR 0028) |

## Versões suportadas

| Versão | Recebe correções |
|---|---|
| Última release | Sim |
| Anteriores | Não |

Antes da v1.0 nada é pronto para produção. Detalhes em [`docs/support-policy.md`](docs/support-policy.md).
